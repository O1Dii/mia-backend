# Таймер

- "Поставь таймер на 5 минут" -> `start` с `seconds` (5 минут = 300) и коротким `label`. Не запускай повторно после успеха.
- `get` читает все таймеры и оставшееся время; отвечай по его тексту, не считай сам.
- `pause`, `resume`, `cancel` принимают `id` из `start`/`get`. Если таймер один, `id` можно опустить; если их несколько и непонятно какой, уточни у пользователя.
- Таймер хранит только срок. Сигнал по окончании приходит отдельным уведомлением, звонок на телефоне делает `device.alarm.set`, если он доступен.
