# Мысли вслух

- `add(text)` сохраняет заметку, `list` показывает все с id, `toggle(id)` отмечает/снимает выполнение, `delete(id)` удаляет.
- Для изменения конкретной заметки сначала вызови `list`; не придумывай id.
- Не пересказывай весь список, если об этом не просили: назови количество и суть.
