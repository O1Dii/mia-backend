# В потоке

- Фокус: `start` на 1500 секунд (25 минут), перерыв: `start` на 300 секунд с label "Перерыв". Новый `start` заменяет текущую сессию.
- `get` показывает остаток, `pause`/`resume`/`cancel` управляют сессией (id не нужен).
- Отвечай коротко; по окончании пользователь получит уведомление отдельно.
