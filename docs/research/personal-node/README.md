## Коротко

Узел — это то же ядро Mia (пакет `mia-node` из этого репозитория) на компьютере пользователя. Он держит одно исходящее
WSS-соединение к серверу Mia, через которое:

- облако видит, что узел в сети, и знает его возможности;
- облачный runtime вызывает файлы и действия на ПК (по согласию ADR-0016) и локальные модели Ollama.

Для режимов «данные дома» и «узел вместо сервера» узел поднимает всё ядро на встроенном Postgres. Клиенты ходят к
нему по TLS 1.3, который заканчивается на самом узле. Relay Mia пересылает зашифрованные байты и не может их прочитать.
