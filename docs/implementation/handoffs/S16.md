## Decisions

- The pinned Google SDK rejects input transcription on its Developer API connector.
  Use official wire transport plus SDK message validation with existing locked
  `websockets==15.0.1`; no private SDK patches or unsupported transparent flag.
- Provider logging is disabled; errors have fixed safe messages without raw chains.
- Resume only at a verified boundary with no pending input; never replay uncertain
  PCM or imply delivery acknowledgement. New audio invalidates an old checkpoint.
- Preferred/planned policy: Fable 5.1 xhigh / Sol xhigh fallback. A prior execution
  hit quota; dispatcher continued the existing implementation with actual
  `gpt-6-astra` xhigh. No model invocation was treated as a second mandatory review.
