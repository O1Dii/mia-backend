## Contracts produced or changed

- `RealtimeClient` creates a new short-lived session and returns a
  `RealtimeConnection`; SDK/OkHttp types do not cross this port.
- `RealtimeConnection` owns independent client sequence IDs, authenticated WSS,
  input control/binary frames, response cancellation, and correlated inbound audio.
- `RealtimeVoiceController` is the S26/S31/S32 entry point and exposes one
  `StateFlow<VoiceSessionState>` rather than independent flags.

## Decisions

- REST and WSS share an origin trust boundary so a compromised session response
  cannot redirect the bearer token to another host.
- Input backpressure fails the active turn after at most 9,600 queued PCM bytes;
  output backpressure closes the bounded event path instead of growing memory.
- A reconnect always creates a fresh backend realtime session and never revives an
  unfinished turn.
