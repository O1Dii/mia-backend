## Decisions

- ChatGPT: no device code — OpenAI's agent sign-in (`dynamic_agent_client`) only allows the
  `http://127.0.0.1:<port>/auth/callback` redirect; developers.openai.com/siwc (sign-in, self-hosted VMs) has no
  device grant. Codex's `--device-auth` belongs to the Codex client and was not reused. Hosted → paste the address.
- One image for API/worker/migrations; web served by the API (no extra nginx root, no second container).
- Secrets generated on the server, split per container; Redis without persistence (TTL keys only).
- `FORWARDED_ALLOW_IPS` trusts docker networks, loopback and the provider gateway `10.0.18.240`.
- Hub card text updated; order 40 unchanged.

## Rollback and redeploy

- Rollback one step (restores POC image, compose, nginx location and card; removes worker/PG/Redis containers,
  keeps their data): `bash deploy/publish-via-shared-server.sh --rollback`.
- Redeploy: `MIA_APK=<apk> MIA_APK_VERSION="0.1.0 (<sha>)" bash deploy/build-release.sh && bash deploy/publish-via-shared-server.sh`.
- New APK only: build Android as above, then `MIA_SKIP_IMAGE=1 MIA_APK=<apk> MIA_APK_VERSION=… bash deploy/build-release.sh`
  and `bash deploy/publish-via-shared-server.sh --apk`.
