USB-connected Samsung SM-S938B (Android 16, API 36). Real Google sign-in,
refresh, logout, and re-login remain **unverified**: the built `liveDebug` app
has no public backend URL or Web OAuth client ID, and the debug application ID

application ID) is still open. S21's `OPEN_ISSUES.md` block records no new
non-blocking issue; the missing OAuth/backend state is a blocker here and in
`STATUS.md`.
