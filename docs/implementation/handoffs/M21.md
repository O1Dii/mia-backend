`session/M21-coordination` (this file + `## M21 inbox`). Backend code unchanged.

## Outcome

New `:core:stt` module recognizes Russian speech on the device with GigaAM-v3 (int8) through
sherpa-onnx 1.13.8 behind `MiaSpeechRecognizer`. Input is a VAD segment of 16 kHz PCM16 built
from the existing `PcmVoiceActivityDetector`; output is text + confidence. On SM-S938B a 3–5 s
utterance decodes in p50 106 ms / max 140 ms (CTC, 4 threads), PSS ~287 MB with the model loaded.
WER 6.9 % on the 30-phrase set (synthetic voice, see limitations). The model is downloaded on
first run with SHA-256 verification; it is not packaged.

## Scope completed

- sherpa-onnx pinned to GitHub release v1.13.8; the AAR is fetched by Gradle into
  `~/.gradle/caches/mia/sherpa-onnx/` and checked against the release SHA-256
  (`633c2432…bd96`). Only `libsherpa-onnx-jni.so` + `libonnxruntime.so` for arm64-v8a are packaged.
- CTC vs RNNT measured on device and host (table below): **default = GigaAM-v3 CTC, 4 threads**.
- Model catalog `GigaAmV3Models` (CTC, RNNT, CTC-punct, RNNT-punct) pinned to HuggingFace commit
  URLs with size + SHA-256; store, installer (resume via Range, https-only redirects), side-load source.
- Cloud fallback interface: `UnconfiguredCloudSpeechRecognizer` stub + `FallbackSpeechRecognizer`.
- 30-phrase benchmark (12 names, 12 mixed RU/EN, 6 commands), scripts, device + host results.

uncompressed: onnxruntime 22.2 MB + JNI 4.8 MB); app debug APK today 13.9 MB without STT.

## Decisions

- **Download on first run, not packaged.** 225 MB exceeds sensible APK size and must not be in git;
  installer verifies SHA-256 per file and resumes. Store root: `Context.noBackupFilesDir/stt-models`.
  Release alternative (Play Asset Delivery) recorded as OI-M21-002.
- **CTC by default** (`GigaAmV3Models.Default`): same WER as RNNT, best name recall (46/54), one
  file, same latency at 4 threads. RNNT stays selectable. Punct models emit Latin names and digits
  (good for display) but lose names; revisit with real speech (OI-M21-003/004).
- `numThreads = 4` (`SherpaOnnxBackendFactory`): −30 % latency vs 2 threads on SM8750.
- Confidence is a heuristic (`ConfidenceSource.HEURISTIC`): sherpa's Kotlin JNI exposes no token
  log-probs (OI-M21-001). Use `TranscriptConfidence.LOW` (0.4) only as a "repeat please" gate.
- Interface name `MiaSpeechRecognizer` (no clash with `android.speech.SpeechRecognizer`).

## Known limitations

- Test audio is synthetic (macOS `say`, voice Milena, clean); real WER will be higher.
- Mixed RU/EN: the Cyrillic-only model drops/garbles some brand names ("Linear", "Slack").
- Only arm64-v8a native libs: other ABIs get `NATIVE_RUNTIME_MISSING` (→ fallback, a stub now).
- Native decode is not interruptible; cancelling `transcribe` returns after the current decode.
- The test app keeps installed models until uninstalled; `device_bench.sh` removes the pushed copies.

- Construct once per voice service/process (`implementation(project(":core:stt"))`):
  ```kotlin
  val store = SttModelStore(File(context.noBackupFilesDir, "stt-models"))
  val device = OnDeviceSpeechRecognizer(GigaAmV3Models.Default, store) // own decode thread
  val stt: MiaSpeechRecognizer = FallbackSpeechRecognizer(device, UnconfiguredCloudSpeechRecognizer())
  ```
- Readiness (`stt.readiness: StateFlow<SttReadiness>`): `NotLoaded` → `prepare()` →
  `Loading` → `Ready(loadMillis)`; or `ModelMissing` (offer download), `Unavailable(reason)`
  (`NATIVE_RUNTIME_MISSING`, …), `Failed` (retry `prepare()`), `Closed`. Call `prepare()` when the
  voice surface opens (~1 s load + ~0.2 s first-launch SHA-256 check).
- Model download (user consent, see OI-M21-002), from a ViewModel/WorkManager coroutine:
  `SttModelInstaller(store, HttpsModelFileSource()).install(GigaAmV3Models.Default) { progress -> }`
  → `SttInstallResult.Installed | Failed(failure, file, detail)`; then `prepare()` again.
- Feed VAD: in the capture collector, per frame
  `val obs = vad.accept(frame, duringPlayback); assembler.accept(frame, obs)?.let { segment -> launch { handle(stt.transcribe(segment)); segment.wipe() } }`
  with `val assembler = SpeechSegmentAssembler()`; `assembler.commit()` for explicit commit,
  `assembler.discard()` on barge-in/cancel. `transcribe` is main-safe and never throws except
  `CancellationException`; results: `Transcript(text, confidence, …)`, `NoSpeech`, `Unavailable`, `Failed`.
- Lifecycle: `stt.close()` on voice teardown (may block ≤ one decode, ~0.1–0.2 s).
- Fakes for controller tests: implement `MiaSpeechRecognizer` directly (see
  `FallbackAndConfidenceTest.Scripted`) or inject `SttBackendFactory` into `OnDeviceSpeechRecognizer`.
- Do not assume: model present on first launch; confidence calibrated; Latin brand names in text.
