  `service_unavailable` envelope when PostgreSQL or Redis is unavailable.
- Every HTTP response receives `X-Request-ID`; request IDs are included in logs.

## Decisions

- Liveness does not touch network dependencies; readiness concurrently pings
  PostgreSQL and Redis.
- The Compose database and Redis are private to the Compose network; only the
  backend port is published (override it with `MIA_BACKEND_PORT`).
- Runtime configuration intentionally does not load `.env`, preserving the
  repository secret boundary.
