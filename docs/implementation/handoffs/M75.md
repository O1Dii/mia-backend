## Outcome

The web client works with chats (ADR-0017): a list with new chat, switching, rename, pin, delete and the retention setting;
a feed per chat addressed as `/chat/<id>`; voice dictation goes into the chat on screen; the result card of a background
task appears in the chat it was started from; the «Сейчас» strip counts timers, alarms, focus sessions down live and shows
background tasks, each with cancel; a tool step shows the redacted arguments and, for a failed call, the reason; after a lost
event stream the chat re-reads its feed; answers can contain Markdown tables. Verified with Playwright against the real
backend wiring (83 passed, 2 skipped = the whole web suite), `tsc`, build and Prettier.

## Scope completed

- Chat list (`ChatList.tsx`): rows with title, preview, time, pin and Telegram marks; actions «Переименовать / Закрепить
  / Открепить / Удалить» (delete asks first); «Новый чат»; «Показать ещё чаты» (cursor); retention select 30/60/180/«Не удалять».
  A column from 1024 px, a drawer below (header buttons «Список чатов» and «Новый чат»).
- Routing and state (`lib/chat.tsx`): `/chat` = latest chat (the address is replaced by `/chat/<id>`), `/chat/new` = draft,
  `/chat/<id>`; per-chat feed with its own cursor; a deleted/foreign chat falls back to the latest; the «Чат» tab and the brand
  link return to the open chat. A draft becomes a chat with the first message (`POST /v1/chats`, then `POST /v1/runs` with
  `conversation_id`). A message sent while the history is still loading waits for it (it was wiped before).
- Resume after reload is per chat (a run of another chat waiting for approval is not drawn here).
- «Сейчас» (`NowStrip.tsx`): `GET /v1/now`, countdown in the browser from `deadline_at` and the server clock skew, paused shown
  frozen, an expired timer leaves at once, jobs with state and a link to their chat; cancel = tile tool call of the plugin
  installation (no model) or `POST /v1/jobs/{id}/cancel`; refresh on focus, after every run, every 30 s (4 s while a job is
  active); when a job disappears the open chat's tail is re-read, which brings in the result card.
- Result cards (`JobResultCard`): `FeedItem.card` rendered as a card with status chip, title, result and «Во входящих».
- Call journal (`ToolSteps`): chip per step; `arguments` (redacted, M73) fold under the chip; a step that did not succeed shows
  «Причина: …» open — `error_detail`, else the public error code in words.
- Lost stream (OI-M41-R1-002, variant c): after `lost` the answer comes from `GET /v1/runs/{id}` and the chat's feed is read again
  (up to 4 times) to add the screen actions (and the text when the run was still going).
- Markdown tables (`lib/markdown.tsx`): GFM tables with alignment, inline marks and https links, in a box that scrolls
  sideways; the speech text drops separators.
- Responsive: 390 / 768 / 1440 px, touch targets ≥ 44 px, no horizontal page scroll.

## Decisions

- Draft chat created with the first message — OI-M75-001. «Сейчас» only on the chat screen — OI-M75-002.
- The open chat shows no preview of itself in the list (the answer is on screen; a second copy broke text locators of older tests).
- Tool journal: failed steps open by default, successful ones folded (OI-M73-002 recommendation (a)); arguments shown as `key: value`
  exactly as redacted by the server.
- The list is a drawer below 1024 px (a 280 px column does not fit a tablet next to the chat).
- Retention select lives at the bottom of the chat list, next to the thing it governs (see OI-M75-006 about the memory page's similar setting).
- `ChatMessage.card` keeps the job card inside the normal message list so paging and ordering are unchanged.

## User check proposal (live, https://mindmapgen.xyz/mia/ after deploy)

**UC-M75-1 — Web: чаты и «Сейчас».** In the browser:
1. «Чат» → write «Привет» → the chat appears in the list on the left (on a phone: button «Список чатов») and gets a short title within a few seconds.
2. «Новый чат» → ask something else (e.g. «Покажи проекты таблицей» with Linear connected) → a table renders; switch back and forth: each chat shows only its own messages.
3. «⋯» → «Переименовать», «Закрепить» (the chat goes to the top), «Удалить» (asks first).
4. «Поставь таймер на 2 минуты» → under the chat title a «Сейчас» card counts down; «×» cancels it. Start a background task («сделай подробный отчёт … в фоне») → it shows in «Сейчас»; when done the result card appears in the same chat (not in another one) and in «Входящие».
5. «Хранить чаты» (bottom of the list) → change to 30 days, reload → stays.
6. Provoke a failed search (e.g. news with an unreachable source) → the step shows «Причина: …»; click a successful step → its arguments (query) are shown.
7. Phone width: the list opens as a drawer, the table scrolls sideways inside its box, nothing scrolls horizontally.
Expected: all of the above without reloading the page. Record notes about layout and wording.
