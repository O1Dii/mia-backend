# M25 handoff

Android branch `session/M25-android-chat` (5 commits on `f4be59b`), coordination branch `session/M25-coordination`
(this file + `## M25 inbox`). Backend code unchanged (no migrations, no contract changes).

## Outcome

The phone's main chat is now one feed on the unified core: history from `GET /v1/feed` with paging upward, a question is a
`Run(profile=chat)` followed over SSE (streaming text, `display` cards, follow-up chips), approvals are cards in the feed.
Voice input is a mic button in the field: on-device STT (M21) with VAD end, the text lands in the field for editing, sending
is manual unless "Отправлять сразу". Every answer has «Озвучить/Остановить» (full text); an answer to a dictated question is
spoken automatically (`response.final.speech`); "Всегда озвучивать ответы" speaks all. A new message or the microphone stops
speech. Voice mode (M22) is a separate button and unchanged; Gemini Live stays hidden (`LIVE_VOICE_ENABLED = false`).
Chat, settings, sign-in, voice screen (orb), approval and list are on the M33 components; phone, landscape and tablet.
Device gate on SM-S938B passed (real UI, STT, TTS, backend; injected speech).

## Decisions

- Single feed, no conversation list: the list screen is restyled but not routed (Gemini Live path only).
- The presenter outlives the screen (kept per account in `AppContainer`): a run goes on while voice mode or settings are open;
  speech stops when the chat leaves composition; returning calls `onShown()` (refresh merges voice turns, dedupes by run+role).
- Auto-speak speaks `response.speech`; «Озвучить» speaks the message's full text (markdown stripped). If a dictation is
  active when the answer arrives, it is not spoken over the user.
- Both new settings default to off (a dictated message is checked before sending; answers are spoken only after dictation).
- Chat runs send `device_id` and handle `device_tool.call` (otherwise a device tool would time out in a chat run); this is the
  M22 channel unchanged, not new device tools.
- Dictation uses the same STT instance as voice mode (one ~290 MB model in memory), hence the visibility change in the runtime.
- Strings: resources with Russian translations; English values keep the old texts so existing tests stay valid.
