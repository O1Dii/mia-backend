# S15 handoff

## Outcome

The backend now has a provider-neutral, bounded realtime v1 WebSocket state
machine with short-lived session creation, injectable bearer authentication,
strict control validation, binary PCM routing, cancellation filtering, and a
deterministic fake realtime provider.

## Scope completed

- Added idempotent short-lived session creation and single-owner connection claims.
- Added injectable REST/WSS bearer authentication hook and standalone FastAPI router.
- Added strict runtime models for all six client control event types.
- Added configure-before-audio handshake, independent client/server sequences,
  binary PCM framing checks, and input commit byte/duration validation.
- Added bounded client/provider queues and controlled backpressure closure.
- Added cancel/disconnect cleanup and stale audio/control filtering by response ID.
- Added deterministic fake transcript/audio/tool/usage events and provider port.
- Added REST, WebSocket, schema, backpressure, cancellation, and disconnect tests.

## Decisions

- Provider input and output are independently bounded; input overflow emits
  `realtime_backpressure`, while a stalled output queue closes as retryable.
- A response is cancellable only after `response.started`; later provider audio
  and controls for its cancelled ID are discarded except `response.interrupted`.
- Missing and foreign/expired/already-claimed sessions share a not-found close path.
- Fake tool events prove transport only; they do not authorize or execute tools.
