## Contracts

- `GET /v1/installations/{id}/tiles/{tile}` → `{installation_id, plugin_id, tile_id, title, resource_uri, html, csp, sizes, mobile, refresh{tool,every_seconds}|null, tools[]}`.
- `POST …/tiles/{tile}/tool-calls {name, arguments}` → `{status, is_error, content, structured_content, error_code}`. Политика: только инструменты
  своей установки (локальное имя или `plugin.name`), `write_external` → 403 `tool_permission_denied` (ничего не выполняется), чужая установка → 404,
  неактивная → 409 `connection_required|tool_consent_required|tool_not_active`. Ошибки роутера — 200 со `status`/`error_code`. Новых кодов ошибок нет.
- Документ: in-process — `resources/read`; `bundled` — файл пакета; без CSP хоста — вставляется CSP+мост (`render_app_html`).
- Миграций и новых настроек нет. Зависимости npm не менялись (`@mcp-ui/client` не нужен; мост написан по спецификации).
