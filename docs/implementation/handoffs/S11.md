## Decisions

- Repositories flush but never commit; `ConversationService` owns complete
  idempotent transaction boundaries through an injected async session factory.
- Foreign and missing conversations share the same not-found result to avoid
  ownership disclosure.
- Entry sequence allocation locks the owned conversation row and increments
  `next_sequence`, so concurrent writers cannot duplicate or reorder a sequence.
- Idempotency compares a canonical SHA-256 request hash and rejects key reuse for
  different payloads without storing the original request body.
