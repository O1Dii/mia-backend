# M41-R1 handoff

## Outcome

«Подключи Telegram-бота» now shows a button «Открыть Telegram» with the one-time bot link under the answer on web and Android, live and after a reload, until the link expires (then disabled). The link never reaches the model: the tool text only says that a button is on screen, and neither the tool result nor the next run's history carries it. The mechanism is generic: any trusted (in-process) tool can attach one screen-only action.

## Scope completed

- Shared value type + validation `app/core/ports/screen_action.py`: `_meta["mia/action"] = {kind: "open_url", url, label (1..40), expires_at?}`; only `https://` with a host (no userinfo) or `tg://`; expired listing drops `url`, adds `expired: true`.
- Kit helper `screen_action(url, label, expires_at=)` + `ok(summary, data, action=)` (`app/modules/plugins/builtin/kit.py`).
- Router: validated action from the result `_meta` of in-process servers only → `ToolOutcome.action`; failed calls and remote servers carry none.
- Run engine: `tool.call.completed.action`; up to 4 actions per run stored with the answer (`RunFeed.record_answer(actions=)`); model content unchanged (`_model_result` never sees it).
- Feed: `content.actions` of the assistant entry; `FeedItem.actions` (only when present), expired → no `url`.
- `builtin.telegram.connect_bot`: link moved from `structuredContent` to the action; structured is `{linked: false, expires_at}`; no link → tool error. SKILL.md line updated. Tool description NOT changed (would change the consented tools digest).
- Web: `ScreenActions` in `ChatParts.tsx` (link button `target=_blank rel=noopener`, disabled «… · ссылка устарела», re-renders at expiry); `ChatMessage.actions` from events and feed.
- Android: `ScreenAction` + codec (`core/network`), `ChatMessage.actions`, presenter collects per run, `ChatScreen` button (`MiaButton`), `ExternalLinks` opens `t.me` bot links as `tg://resolve?domain=…&start=…` first (Telegram app), then the https link.

## Decisions

- Only in-process (builtin/declarative) servers may attach an action: a remote server could otherwise put a phishing button with Mia's styling (OI-M41-R1-001).
- Action lives in `_meta`, not `structuredContent`: structured content goes to MCP Apps and is plugin data; `_meta` is the MCP place for host hints.
- Feed strips the URL after `expires_at`; clients also check expiry on render and on tap.
- Android opens `t.me` bot links via `tg://resolve` first: Telegram's https app links are not verified, so Android 12+ would otherwise open the browser.
- `connect_bot` description unchanged to keep `tools_digest` of existing installations (server has Telegram installed).
