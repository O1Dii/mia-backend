## Decisions (made autonomously)

- Приёмка идёт на настоящей композиции `install_runtime_api`, а не на ручной сборке модулей (как в web e2e_server):
  так ловятся ошибки стыков (так найдены Telegram-текст и гонка ack).
- Найденные, но не исправленные дефекты закреплены strict xfail: тест сам станет зелёным после repair.
- Лимит голоса ≤ 2 tool calls — из ADR-0011, поэтому это вопрос пользователю (OI-M60-001), а не дефект.
- M41-R2 не сделан как safe fix: правка в пути подтверждений (router + память + композиция) — это безопасность.
- OI-M74-R1-002 (`notify` без пространства имён) не переименовывался: меняет `tools_digest` core и подсказки модели;
  стенд не валидирует только это событие. Перенесён после MVP (OI-M60-009).
