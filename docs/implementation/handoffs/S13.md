# S13 handoff

## Outcome

The backend now has a provider-neutral normalized AIEvent vocabulary, a text
streaming port, deterministic fake implementation, manual function-call events,
Gemini SDK adapter, and bounded conversation context builder.

## Scope completed

- Added all normalized AIEvent v1 runtime event types and contract projection.
- Added provider-neutral text requests, messages, tool declarations, and port.
- Added a deterministic fake stream with stable ordering and event identifiers.
- Added Gemini text chunk/function-call/usage/error mapping with automatic tool
  execution explicitly disabled.
- Added a strict context budget that preserves stable instruction/profile and a
  contiguous suffix of recent canonical entries.
- Added orchestration that builds requests and streams events without executing tools.

## Decisions

- Google SDK objects are converted inside `gemini_text.py` and never cross the port.
- Provider error text is normalized to fixed safe messages; raw SDK response text is
  not emitted or logged.
- Undeclared function calls become `provider_invalid_response`; automatic SDK
  function execution is disabled so S17 retains policy control.
- The fallback token estimator is conservative for UTF-8/Cyrillic text and can be
  replaced through its protocol when a production tokenizer is selected.
