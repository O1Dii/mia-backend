## Outcome

Package `team.google-calendar` (remote MCP, OAuth, read-only) with tools `today_events` and `list_events` (both `risk: read`, `voice: true`), the tile «Сегодня», a skill, and the server code that implements the tools over Google Calendar REST `events.list`. Contract tests on recorded Google responses pass (18, incl. Postgres publish/install/connect/call). PARTIAL: the live smoke needs the user's Google OAuth client and an interactive sign-in, and Mia cannot yet connect to Google's authorization server (OI-M42-001); the server is not deployed (OI-M42-002).

## Scope completed

- `plugins/google-calendar/mia.json`, `SKILL.md`, `ui/today.html` (bundled tile, no external URLs, `textContent` only, passes publication checks).
- `plugins/google-calendar/server/calendar_mcp.py`: MCP server (`build_server`), forwards the bearer to `GET /calendar/v3/calendars/{id}/events` (`singleEvents`, `orderBy=startTime`), drops cancelled events, all-day aware, "today" computed in the given IANA timezone, range <= 31 days, 401/403/404/5xx -> tool errors without the token. Scope `calendar.events.readonly`. Not stored in releases (the catalog ignores `.py`), it ships separately.
- Tests `tests/plugins/google-calendar/` with recorded fixtures.

## Decisions

- Declarative host cannot call REST, so no declarative plugin; no `app.` change is needed for the contract tests. Remote kind chosen, server code lives in scope next to the package.
- Scope `calendar.events.readonly` (least privilege). Consequence: no `calendars.get` / settings, so the user timezone comes from the caller (tile: `Intl`; model: skill instructs to pass it), default UTC.
- Tool ids are `today_events` / `list_events`; manifest id `team.google-calendar` (the id grammar forbids underscores).
- `server.url` is the placeholder `https://calendar-mcp.mia.example/mcp` (reserved example TLD); change it with `network` before publishing.
