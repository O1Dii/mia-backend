# M14 handoff

Branch `session/M14-builtin-plugins`; `backend_head_commit` = last code commit, the handoff commit follows it.

## Outcome

Six builtin plugins (timer, alarm, notes, focus, internet, news) are in-process MCP servers on the
MCP Python SDK (`mcp==2.2.0`). Each has `mia.json`, `SKILL.md`, `server.py` and an MCP App tile
served as a `ui://` resource that its tools reference. State lives in `PluginState` (M10) keyed by
the call's `mia/installation_id`. A declarative host runs `server.kind: declarative` manifests
(`state.patch`, `model.prompt`, `fields`/`html` views), and `scripts/convert_manifest_v2.py` turns
POC v1/v2 manifests into declarative `mia.json`. One factory serves both kinds to M13's router.

## Deviations

- **Package location (dispatcher adjustment):** builtin packages live at `app/plugins/builtin/<id>/`, not
  `plugins/builtin/<id>/`, because the M00 schema needs `server.module` to match `^app(\.[a-z_][a-z0-9_]*)+$`.
  Plugin ids are `builtin.<name>`, module `app.plugins.builtin.<name>.server`. The M00 example
  `timer.mia.json` still says `app.plugins.timer.server`; it is not edited (still valid).
- **Two small test edits outside the card scope** (`tests/hardening`, `tests/web_poc`) keep the gate green after
  `mcp` installs `httpx2`; M13 will hit the same, expect identical hunks (OI-M14-007).
- Not ported: `mia.clock` (not in the card, OI-M14-003).

## Public API (exact signatures)

```python
# app/modules/plugins/builtin/factory.py  (re-exported from app.modules.plugins.builtin)
InprocessFactory = Callable[[Mapping[str, Any], Path], MCPServer]
def make_inprocess_factory(services: HostServices) -> InprocessFactory      # (manifest, plugin_dir) -> server
def build_inprocess_server(manifest: Mapping[str, Any], plugin_dir: Path, *, services: HostServices) -> MCPServer
# builtin: imports server.module (only under "app.plugins.builtin.", PLUGIN_ID must equal manifest id)
# declarative: build_declarative_server(manifest, services, plugin_dir); other kinds -> UnsupportedServerError
# app/modules/plugins/builtin/manifests.py
class BuiltinManifestSource:  # BuiltinManifestSource(root: Path | None = None)
    def list(self) -> list[BuiltinPlugin]                       # sorted by (id, version)
    def get(self, plugin_id: str, version: str | None = None) -> BuiltinPlugin | None
class BuiltinPlugin:  manifest: Mapping; directory: Path; plugin_id; version; skill_text()
# app/modules/plugins/builtin/services.py
HostServices(state=InMemoryPluginStateStore(), clock=time.time, new_id=..., web: PublicWeb|None, llm: HostLlm|None)
class HostLlm(Protocol): async def generate(self, prompt: str, *, identity: CallIdentity, plugin_id: str) -> LlmReply
SqlPluginStateStore(session_factory: async_sessionmaker[AsyncSession])
# app/modules/plugins/declarative/convert.py
def convert_manifest(source: Mapping, *, category: str = "productivity") -> ConvertedPlugin  # .manifest .skill_md .warnings
```

Identity: `tools/call` `_meta` keys `mia/user_id`, `mia/workspace_id`, `mia/installation_id` (required),
`mia/run_id` (optional). Missing or blank -> MCP tool error naming the keys, no crash (both `auto` and
`legacy` client modes tested). `SqlPluginStateStore` also checks that the installation belongs to the
caller's workspace/user, is `active` and belongs to the plugin asking.

## Plugin contracts (for M15/M16/M31)

All results: `content` = Russian summary for the model, `structuredContent` = data for the tile
(`items`/`notes`/..., `changed`, `server_time_ms`). Tool `_meta` carries `ui.resourceUri` and the flat
`ui/resourceUri`; resources are `text/html;profile=mcp-app` with CSP and bridge already injected.

| Plugin | Tools (voice) | State in PluginState |
| --- | --- | --- |
| `builtin.timer` | start*, get*, pause*, resume*, cancel* (up to 10 timers, `id` optional if unambiguous) | `{"items":[item]}` |
| `builtin.focus` | same, one slot, `start` replaces (default 1500 s) | `{"items":[item]}` |
| `builtin.alarm` | set* (`at` ISO with offset, <= 31 d), get*, cancel* (`id` / `cancel_all`) | `{"items":[item]}` |
| `builtin.notes` | add*, list*, toggle*, delete | `{"notes":[{id,text,done,created_ms}]}` |
| `builtin.internet` | search*, news*, read (all `read` risk, stateless, `untrusted_content: true`) | none |
| `builtin.news` | refresh (LLM + web), get*, set_schedule | `{topics, interval_minutes, items, summary, updated_ms, model, error}` |

`item` = `{id, label, status: running|paused|scheduled, deadline_ms, remaining_ms, duration_ms, created_ms}`
(`at` for alarms). M16 scans `deadline_ms` (`deadlines.pending(items)`); an expired item stays 24 h (OI-M14-004).
Declarative servers add an app-only `get_state` (OI-M14-001); `state.patch` -> `write_reversible`+voice,
`model.prompt` -> `read`, `{{input}}`/`{{name}}`/`{{state.key}}` templating, reply stored as `state.answer`.
