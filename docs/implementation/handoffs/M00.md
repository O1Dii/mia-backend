## Decisions

- `server.kind` = `builtin | remote | declarative`; `worker` reserved (additive
  later). Device tools are registered per device, not declared as plugins;
  manifests may list `requires.deviceTools`.
- Remote `auth` adds `mia_token` (MindWeaver accepts Mia tokens, Review §8.3).
- Approvals are single-use and bound to `args_hash` + tool; decision channel
  `voice_trusted` only for trusted people (Review §7.5).
- Device results return by `POST /v1/runs/{run_id}/device-tool-results`; calls
  go out as `device_tool.call` run events. Read timeout → `failed`, write
  timeout → `uncertain`.
- `POST /v1/chat/completions` is the only `/v1` mutation exempt from
  `Idempotency-Key` (`x-mia-idempotency: exempt`); validator enforces it.
- OpenAPI is validated with `jsonschema_path` handlers that map
  `https://contracts.mia.local/mvp/v1/*` and `file://` to local files and refuse
  anything else (no network). `validate_spec` was not reused for mvp because
  it ignores `base_uri`.
