## Decisions

- Optimistic local insert is guarded synchronously to prevent two rapid taps
  creating separate operations. Stream retries reuse the stored local ID.
- Failed local enqueue restores the draft in the input and exposes Retry.
- Retain canonical server entries as authority on completion; partial live text
  remains visible if a terminal cache read fails.
