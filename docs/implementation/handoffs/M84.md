## Outcome

«Ещё» → «Устройства» on the web, and «Настройки» → «Устройства» in the app (the same screen through the M24 WebView), list
the account's phones and browsers with «онлайн» / «был(а) N мин назад» / «офлайн» / «нет push», the current device first
(«Это устройство»), and a separate «Облако Mia» row with what works without devices. A device card shows model/OS/app
version, when it was connected and last seen, push and notifications, and for a phone every capability: on in Mia, the
Android permission, whether other devices may ask, which installed plugins use it («Где работает»), what the model sees;
the persistent permissions with «Отозвать», the access log, «Переименовать» and «Отключить устройство». No phone numbers
and no content anywhere: names, states and times only. Personal Node (M86) plugs into the same list as one more source.

## API (`app/modules/devices/**`, `app/api/v1/device_directory.py`)

Any signed-in session of the account (bearer, WebView, browser cookie):

- `GET /v1/devices` → `DeviceList` (`items`, `cloud`, `server_time`, `online_window_seconds`);
- `GET /v1/devices/{id}` → `DeviceDetail`; `PATCH /v1/devices/{id}` `{name|null}` (null = default name);
- `POST /v1/devices/{id}/disconnect` → 204; `409 device_is_current`, `404 device_not_found`;
- `POST /v1/devices/heartbeat` `{report?}` → `{device_id, kind, next_heartbeat_seconds: 60}`; the report
  (`DeviceStatusReport`: OS, model, app version, notifications, OS permission per capability) is stored only from the
  app's bearer; strings are cleaned of control characters and phone numbers.
- M70 paths opened to the owner's other sessions (OI-M84-002): `GET …/grants`, `DELETE …/grants/{grant_id}`,
  `GET …/access-log`. Queued calls and capability switches stay phone-only.

Design: `DeviceSource` protocol (`SqlPhoneSource` — `devices` with an active refresh family; `SqlBrowserSource` — live
`web_sessions` not bound to a device). `DeviceDirectory.add_source()` is the M86 slot: `kind="node"` is already in the
contract enum, presence by connection via `PresenceTracker.connected/disconnected` (`via: "connection"`). Presence rule
(`presence_of`): open connection or contact ≤ 120 s → online; phone without usable push → `no_push`; contact ≤ 60 min →
`recent`; else `offline`. Contact = every authenticated request (new `RequestAuthenticator.add_observer`) + client
heartbeat; kept in memory, written ≤ once a minute to `devices.last_seen_at` / `web_sessions.last_seen_at`.
Capabilities: `CAPABILITIES` + declared device tools (`enabled`), report (`os_permission`), M71 setting (`remote`), active
plugins' `requires.deviceCapabilities` (`plugins`). Cloud row: active plugins' «Где работает» (M72 helpers).

Renamed phones: consent texts and `target_device_name` use the new name (`SqlDeviceAccessStore.device_name/declarations`
coalesce `display_name`); a new sign-in keeps the user's name (sign-in only updates `device_name`).

## Known limitations

- A phone in the background is «был(а) N мин назад» / «офлайн» even if push would wake it — that is the meaning of the
  statuses; «нет push» marks phones that cannot be woken.
- The phone's report appears after the app has been opened once with this version.
- Browser names come from the User-Agent at the first request after sign-in (sessions created before the deploy get it on
  their next request).

## Proposed user check (UC-M84-1, после деплоя backend и установки APK этой ветки)

1. На компьютере откройте Мию в браузере → «Ещё» → «Устройства». Видно: этот браузер («Это устройство», «онлайн»), ваш
   телефон и «Облако Mia» с плагинами. Если есть второй телефон или второй браузер — они тоже в списке.
2. Откройте Мию на телефоне и подождите минуту: на компьютере телефон «онлайн», модель и версия Android верные. Закройте
   приложение на телефоне: через 2–3 минуты статус «был(а) N мин назад» (или «нет push», если push не настроен — запишите,
   что видно).
3. Нажмите на телефон: в разделе «Что может выполняться на этом телефоне» поиск в контактах показывает, есть ли разрешение
   Android; дайте или заберите разрешение «Контакты» на телефоне, откройте приложение — через минуту карточка обновилась.
   У «будильник в «Часах»» указан плагин «Будильник», если он установлен.
4. Если на телефоне есть постоянное разрешение для браузера (UC-M71-1, п. 4), оно видно в «Постоянные разрешения»;
   «Отозвать» на компьютере — следующий запрос снова спрашивает на телефоне. «Показать журнал доступа» — записи с решениями.
5. На телефоне: «Настройки» → «Устройства» — тот же экран, телефон отмечен «Это устройство».
6. «Переименовать» телефон на компьютере — новое имя видно в списке и в тексте запроса на телефоне.
7. Тестовый браузер (другой браузер или окно инкогнито, вход в тот же аккаунт): в первом браузере откройте его карточку →
   «Отключить устройство» → во втором браузере любое действие просит войти. Отключать телефон — только тестовый:
   приложение выйдет из аккаунта.
Ожидаемо: нигде нет номеров телефонов и содержимого; замечания по внешнему виду (светлая/тёмная тема, телефон) записать.
