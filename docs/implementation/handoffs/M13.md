# M13 handoff

Branch `session/M13-tool-router`; `backend_head_commit` = last code commit, the handoff commit follows it.

## Outcome

`McpToolRouter` implements the `ToolRouter` port and is wired into the run engine with a
Postgres `ApprovalService`. A model tool call reaches installed plugins over MCP (SDK
`mcp==2.2.0`, spec 2026-07-28: in-process via an injected factory, remote via Streamable
HTTP behind an SSRF guard), device tools via `DeviceToolChannel`, and core extension points.
Policy: caller-scoped lookup, JSON Schema args, profile/app scopes, consented tools digest,
`write_external` → single-use approval bound to `args_hash`, `operation_id` audited before
dispatch, one attempt (timeout of a write → `uncertain`). Output reaches the model only framed
as untrusted data; `structuredContent` goes to `tool.call.completed` (display). All DoD
negative tests and e2e (in-process + HTTP, through the engine) pass on memory and Postgres.

## Decisions

- One short-lived SDK `Client` per list/call (`mode="auto"`: `server/discover`, fallback `initialize`);
  `tools/list` cached per plugin version (in-process) / installation (remote) for `TOOLS_LIST_CACHE_SECONDS`.
- SSRF: https only, no IP literals/userinfo, host ∈ `permissions.network` (∩ global allow-list), every
  DNS answer must be public, connection pinned to the vetted IP (Host + SNI keep the name), checked on
  every request incl. redirects; SDK follows only same-origin redirects.
- Failure before delivery → `failed`; delivered write with timeout/transport error → `uncertain`;
  JSON-RPC error/`isError` → `failed` `tool_execution_failed`. No retries anywhere.
- Approvals: run+tool+`args_hash` bound, consumed atomically (`SELECT … FOR UPDATE`), usable until
  `expires_at` + 30 s grace for wake-up; waits wake in-process, poll 0.5 s for other instances.
- Grants are not enforced beyond status/digest/network/scopes (vocabulary undefined, OI-M13-002).
- `mcp==2.2.0` pulls `httpx2`, which starlette's `TestClient` now prefers: two legacy tests adapted
  (`httpx2.Response`, non-optional cookie asserts); `tests/e2e_tools/harness.py` `AuditRow` turn ids
  Optional (nullable columns); `tests/runs/test_wiring.py` asserts the wired router. M14 pins the same
  SDK and may carry identical test edits — keep one copy.
