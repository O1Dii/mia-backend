# S27 handoff

## Outcome

The foreground-only, on-device experimental wake engine, local enrollment,
480 ms pre-roll, settings UI, coordinator, and corpus evaluation harness are
implemented and pass JVM/lint gates. S27 is **PARTIAL**: Android app/root wiring
is integration-owned, and no independent speech corpus or attached physical
device was available for quality, CPU, thermal, and eight-hour battery gates.
Do not mark the W5 wake gate passed or unblock S28 from this result alone.

## Scope completed

- `WakeWordEngine` port, spectral-template KWS with three local enrollment
  samples, 40 ms streaming segmenter, bounded candidate and pre-roll buffers.
- `WakeConfiguration` persists only spectral templates in app-private storage;
  wake is disabled by default. No pre-trigger network path exists in `core/wake`.
- `ForegroundWakeCoordinator` owns wake/enrollment microphone capture while
  foreground and stops it before invoking the trigger callback. `SettingsRoute`
  exposes enrollment and enable/disable controls.
- Independent WAV corpus harness checks distinct enrollment/evaluation files
  and reports clip false rejects and streaming false accepts per negative hour.

## Contracts and integration

- Constructor: `ForegroundWakeCoordinator(audio: DuplexAudioEngine,
  configuration: WakeConfiguration, scope: CoroutineScope,
  onDetected: (WakeWordDetection) -> Unit)`. Use `state`, `setForeground`,
  `setEnabled`, `beginEnrollmentSample`, `finishEnrollmentSample`, `close`.
- `onDetected` runs synchronously after wake capture stops. `preRoll` is local
  diagnostic PCM only, **never upload it**; it is zeroed when callback returns.
  The injected audio engine remains caller-owned after coordinator `close()`.
- `DuplexAudioEngine.capturedAudio` has one consuming pipeline. Do not start
  `RealtimeVoiceController` on the same engine while wake is listening. Keep
  wake foreground false while the voice flow owns the microphone.
- Integrator-owned root edit: add `":core:wake",` immediately after
  `":core:audio",` in Android `settings.gradle.kts` `include(...)`.
  S27 intentionally restored its temporary local edit before code commit.
- Integrator-owned app route: wire `SettingsRoute` callbacks/state, microphone
  permission, resumed/paused lifecycle, and trigger navigation into voice.
