## Outcome

The voice screen can copy/share the last 20 turns' measurements: long-press on the «Первый звук через N мс» line puts a text table on the clipboard and
opens the system share sheet. The header carries p50 and p95 of first sound, so UC-M60-8 no longer needs numbers retyped by hand. The action is not behind
`BuildConfig.DEBUG`: it is in `assembleLiveDebug` (the APK users install).

## Scope completed

- `VoiceMetricsExport` (new, `feature/voice`): `percentiles()` (p50 = median, mean of the two middle values for an even count; p95 = nearest rank
  `ceil(0.95·n)`, i.e. the 19th of 20 — the UC-M60-8 convention) and `format(turns, limit = 20)`. Output (Russian): title, «Ходов: N», «Первый звук: p50 … мс,
  p95 … мс (по K ходам со звуком)», «Без звука: M» when any, then one row per turn: `№ | итог | первый звук, мс | откуда | STT, мс | старт run, мс | TTS, мс`.
  No transcript, run id or other personal data.
- `FirstSoundLine` (new composable) replaces the three lines in `CascadeVoiceContent`: the line, long-press (`combinedClickable`, accessibility label
  «Скопировать замеры»), and a hint «Удерживайте строку, чтобы скопировать замеры». The line now also appears after a turn without sound («Нет звука»), so the export
  is reachable after any turn. `shareVoiceMetrics()` = clipboard + `ACTION_SEND` chooser, each in `runCatching`.
- Minimal hook in the existing screen: one optional parameter `onExportMetrics: (() -> Unit)? = null` on `CascadeVoiceContent`, wired in `CascadeVoiceRoute` to
  `controller.turnHistory` (existing, up to 100 turns). No controller/state changes.

## Proposed user step for UC-M60-8 (plain Russian, replaces «переписать с экрана»)

После каждого ответа ничего не переписывать. Когда все 20 фраз сказаны, на экране голоса **нажать и подержать строку «Первый звук через N мс»** (под ответом).
Откроется меню «Поделиться», а текст уже скопирован: вставить его в сообщение (или в заметку) и отправить. В начале текста сами p50 и p95; их и проверять
(p50 ≤ 2500 мс, p95 ≤ 4000 мс). Строки таблицы «№ | итог | …» показывают каждый ход; ходы с итогом «не расслышала» посчитать для «не больше 2 раз», а фразы,
которые распознались неверно, дописать руками (текст фраз в замеры не попадает).

## Known limitations

- The table is built from the controller's history of the current voice screen; leaving the voice screen closes the controller and the history is gone — export before leaving.
- «Первый звук» of a turn is measured from the last voiced frame (speech end), as before; the export does not change what is measured.
