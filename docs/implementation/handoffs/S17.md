# S17 handoff

## Outcome

The first read-only tool, `system.get_current_datetime`, now has an explicit
allow-list/policy/executor and durable user-scoped audit. Text SSE performs a
bounded manual function-call loop; realtime gates provider tool events through
the same executor and sends an explicit Gemini Live tool response. No write tool
is registered or enabled.

## Scope completed

- Strict Pydantic input/output models; unknown, invalid, oversized, forged-risk,
  scope-denied and confirmation-required requests fail closed.
- 2-second default timeout, 4 KiB arguments, 2 KiB output and idempotent audit
  keyed by user/call ID; cancellation and failures are recorded.
- Text tool progress/result SSE plus canonical tool-call/result history; tool
  feedback is a provider function response, never promoted to system instruction.
- Realtime ignores provider-claimed tool completion and emits only executor
  outcomes; Gemini Live maps public IDs back to wire IDs for explicit responses.
