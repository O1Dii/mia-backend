# S26 handoff

## Outcome

Local PCM VAD, hybrid end-of-speech commit, full-duplex capture, barge-in
flush/cancel, old-response discard and latency metrics are implemented and pass
JVM, lint, fixture, APK and aggregate Android gates. S26 remains PARTIAL because
no physical device is attached, so the required <200 ms hardware gate was not run.

## Scope completed

- Energy-based 40 ms PCM16 VAD with two-frame speech onset, five-frame silence
  endpoint, bounded voiced pre-roll, and higher playback threshold.
- Capture remains active after input commit. Local silence commits automatically;
  matching server speech-stop can commit earlier; manual commit still works.
- Detected speech during playback synchronously flushes AudioTrack, sends
  `response.cancel`, opens a new input stream and sends the voiced pre-roll.
- Retired response/turn IDs prevent late audio, playback-start, interruption and
  turn-completion events from resetting a new utterance.
- `BargeInMetrics` exposes speech-to-flush and speech-to-cancel-send milliseconds;
  debug voice route can display the last speech-to-flush value.

## Changes and contracts

Android `core/audio/**/PcmVoiceActivityDetector.kt` adds `VadConfig`,
`VadObservation`, and `PcmVoiceActivityDetector`. `feature/voice/**` adds duplex
barge-in orchestration, reducer transition, deterministic tests and a debug-only
physical AudioTrack latency harness. `RealtimeVoiceController.bargeInMetrics` is
the downstream debug/telemetry entry point. No shared REST/realtime schema,
Gradle root, migrations, config variables or secrets changed.

## Decisions and limitations

- S24 `cancelPlayback` already implements synchronous pause/flush; S26 calls it
  before sending `response.cancel`, avoiding an extra audio-engine API change.
- RMS thresholds are conservative defaults, not device-calibrated speech/echo
  guarantees. S31 should measure real acoustic barge-in and tune AEC/routing;
  this is not represented as a passed physical gate.
- Provider-side speech-stop currently normally follows client commit; local VAD
  is the operative endpoint, while early server-stop handling remains safe.
