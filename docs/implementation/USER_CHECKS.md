# Проверки, которые требуют участия пользователя

Единый список ручных проверок: телефон в руках, живой голос, интерактивный вход,
оценка дизайна. Агент не может выполнить их сам.

**Для агентов.** На вопросы «какие проверки за мной», «что мне проверить», «user checks»
выдавай пользователю таблицу «Открытые» из этого файла: коротко и с шагами.
- Когда пользователь сообщает результат, перенеси строку в «Выполненные» с датой и итогом.
  Результат также запиши в `STATUS.md` у соответствующей волны.
- FAIL или замечание — это повод для repair-сессии или записи в `OPEN_ISSUES.md`.
- Новые проверки добавляет integrator волны или сессия, у которой в DoD есть ручной шаг.

Подготовка для проверок на телефоне: backend запущен на хосте, телефон SM-S938B подключён
(USB `adb reverse` или та же сеть), в приложении выполнен вход Google.
