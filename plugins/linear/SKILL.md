# Linear

- «Мои задачи» = `list_issues` с `assignee: "me"`. Для списка «в работе» добавляй фильтр по статусу, для «срочных» — по приоритету; не выдумывай идентификаторы команд, статусов и меток — сначала `list_teams`, `list_issue_statuses`, `list_issue_labels`.
- Одну задачу открывай через `get_issue` по идентификатору вида `ENG-123`.
- `create_issue` и `update_issue` меняют данные пользователя. Перед созданием убедись, что известны команда и заголовок; в ответе назови идентификатор созданной задачи.
- `create_comment` виден другим людям и рассылает уведомления: показывай текст комментария перед отправкой.
- Удалять задачи этот плагин не умеет; если просят удалить, предложи перенести задачу в статус «Canceled».
- Голосом отвечай коротко: количество задач и две-три самые важные по названию, без идентификаторов, если не спросили.
