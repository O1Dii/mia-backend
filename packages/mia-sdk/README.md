# MIA SDK — local POC

Плагин = skill + actions + state + view + необязательные downloads.
Этот пример использует установленный `mia.timer`, выбранную в MIA модель и тот же таймер, что web-дашборд.

1. Запустите MIA API на `127.0.0.1:8001`, web на `127.0.0.1:5173`.
2. Установите «Таймер», подключите и выберите модель.
3. Распакуйте архив, запустите в его каталоге `python3 -m http.server 8088 --bind 127.0.0.1`.
4. Откройте `http://127.0.0.1:8088/timer.html`. Не открывайте через `file://`.
5. Нажмите «Подключиться», введите код в MIA → Приложения и разрешите доступ.
6. Напишите приложению «Поставь таймер на 5 минут». Изменение появится и на дашборде.

```js
import { MiaClient } from './mia-sdk.mjs';
const mia = new MiaClient({ pluginId: 'mia.timer' });
const pair = await mia.beginPair(); // user_code показываем, device_code не логируем
// Пользователь подтверждает user_code в MIA. Poll не чаще interval секунд.
await mia.pollPair(pair.device_code);
const result = await mia.generate([{role:'user', content:'Поставь таймер на 5 минут'}]);
const snapshot = await mia.state();
await mia.invoke('mia_timer__pause', {});
```

`generate` всегда использует текущую выбранную модель. Токен ограничен одной установкой плагина и даёт право обращаться к модели (с возможными расходами у провайдера); UI запрашивает это согласие при привязке. `invoke`/`state` не могут работать с другими плагинами. Ключи провайдеров не передаются приложению. Для повторного запроса после обрыва передавайте тот же `requestId`; новый ID — новое действие. SDK не повторяет команды автоматически.

Токен хранится только в памяти SDK, действует максимум час и отзывается из MIA. Перезагрузка приложения требует новой привязки. Сессии, подключения и состояние POC живут в памяти сервера до 8 часов/перезапуска. Это локальная идентичность `subject_id`, не production OAuth и не публичная учётная запись. Смотрите `docs/PLUGIN_DEVELOPMENT.md` в репозитории для перехода на общий auth backend и правил авторских HTML view.
